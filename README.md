# Deck

Application personnelle (web app installable) : accueil, calendrier, productivité, développement, sport, notes.

Version 1 : la maquette en plein écran, données d'exemple enregistrées sur l'appareil. Prochaine étape : Supabase et connexion à Claude (MCP).

Installer sur iPhone : ouvrir le site dans Safari, Partager > Sur l'écran d'accueil.
